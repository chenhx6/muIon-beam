# File Naming Glossary

Generated from `00_project/config/naming_policy.yaml`. Do not edit this file directly.

## Format

```text
YYYYMMDD_HHMM-object_id-topic-artifact_type-vNN-locale.extension
```

The timestamp is one field. Its internal separator is `_`; later fields use `-`; words inside fields use lower `snake_case`.

## Stable identifiers

The numeric suffix is a registration sequence within its object namespace. It is not a physical parameter.
