## Canonical relationships

- `Lstage1 = stage1_total_length = stage1_entrance_margin + 4*electrode_thickness + V1_to_V2_clear_spacing + V2_to_V3_clear_spacing + V3_to_V4_clear_spacing + stage1_exit_margin`.
- `V2 = V1 + voltage_difference_V1_to_V2`; `V3 = V2 + voltage_difference_V2_to_V3`; `V4 = V3 + voltage_difference_V3_to_V4`.
- `S_local = Ne_number_density * SN_muNe(Ktotal)`, where the supplied table is the Geant4 11.3.2 mean electromagnetic stopping baseline.
- `transport_survival` means reaching the explicit exit plane without an electrode/wall hit; it is not a physical muon survival probability.
